EVIDENCE-FIRST MODEL

Prices update automatically; fundamentals require a source record.

NSE Insight separates market data from company fundamentals. Market prices and volumes can be refreshed from the NSE market-statistics pages. Fundamental evidence is only admitted when a row includes a financial period and an HTTPS source document.

FUNDAMENTAL PIPELINE

Verified report → derived ratios → score

The verified input file stores report facts such as EPS, book value per share, profit, revenue, equity, EBIT, finance cost and dividends. The build script derives ratios including P/E, P/B, ROE, margin, interest cover, dividend yield, payout ratio and growth. P/E, P/B and dividend yield are recalculated using the latest saved NSE price.

GUARDRAILS

Evidence before a signal

Incomplete evidence is not treated as certainty. Securities with weak fundamentals coverage remain classified as insufficient evidence even when market-price information is available. Governance flags can also override an otherwise strong quantitative score.
